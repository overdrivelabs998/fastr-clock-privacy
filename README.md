# Fastr Clock — Privacy Policy

Public hosting for the Fastr Clock privacy policy, referenced from the app's
Google Play listing and from Profile → Data & privacy inside the app.

**Live page:** https://overdrivelabs998.github.io/fastr-clock-privacy/

Languages: English, ไทย, 日本語 (same three the app ships).

The app itself lives in a separate repository. This one exists solely so the
policy can be served over GitHub Pages, which requires a public repo.
