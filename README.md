# Fastr Clock — Privacy Policy

Public hosting for the Fastr Clock privacy policy and data deletion
instructions, referenced from the app's Google Play listing and from
Profile → Data & privacy inside the app.

**Privacy policy:** https://overdrivelabs998.github.io/fastr-clock-privacy/
**Delete your data:** https://overdrivelabs998.github.io/fastr-clock-privacy/delete-data.html

Languages: English, ไทย, 日本語 (the same three the app ships).

The app itself lives in a separate repository. This one exists solely so these
pages can be served over GitHub Pages, which requires a public repo.
